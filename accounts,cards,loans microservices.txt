Accounts Microservice – Functionality

• Customer Registration
    • Customer ka name, email, mobileNumber save karta hai.
    • Mobile number ke basis par check karta hai ki customer already registered hai ya nahi.

• Account Creation
    • Customer successfully create hone ke baad uske liye new bank account create hota hai.
    • Account details:
        • accountNumber
        • customerId
        • accountType
        • branchAddress
    • Account number randomly generate kiya ja raha hai.
    • Default account type Savings hai.

• Fetch Account
    • mobileNumber se customer ko find karta hai.
    • Customer ke customerId se uska Account find karta hai.
    • Customer + Account details ko ek saath CustomerDto me return karta hai.

• Update Account
    • accountNumber se existing Account find karta hai.
    • Account details update karta hai.
    • Saath hi associated Customer ki details bhi update karta hai.

• Delete Account
    • mobileNumber se Customer find karta hai.
    • Customer ke customerId se Account delete karta hai.
    • Uske baad Customer ko bhi delete karta hai.

Loans Microservice – Functionality

• Loan Creation
    • Customer ke mobileNumber ke basis par loan create karta hai.
    • Check karta hai ki given mobileNumber par loan already registered hai ya nahi.
    • Agar loan already exist karta hai to LoanAlreadyExistsException throw karta hai.
    • New loan create hone par:
        • loanNumber randomly generate hota hai.
        • mobileNumber customer ka save hota hai.
        • Default loanType Home Loan hota hai.
        • totalLoan new loan limit ke according set hota hai.
        • amountPaid initially 0 hota hai.
        • outstandingAmount initially totalLoan ke equal hota hai.

• Fetch Loan
    • mobileNumber se existing loan find karta hai.
    • Agar loan nahi milta hai to ResourceNotFoundException throw karta hai.
    • Loan details ko LoansDto me convert karke return karta hai.

• Update Loan
    • loanNumber ke basis par existing loan find karta hai.
    • Loan details ko LoansDto ke according update karta hai.
    • Updated loan ko database me save karta hai.

• Delete Loan
    • mobileNumber se existing loan find karta hai.
    • Loan ke loanId ke basis par loan ko database se delete karta hai.
    • Loan successfully delete hone par true return karta hai.
